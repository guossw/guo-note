## 一句话地图

- **大模型（LLM）**：会说话，但记性差、知识有时过期。
- **RAG**：给 LLM 接上私有知识库，回答更贴合你的资料。
- **MCP**：LLM 调用外部工具时使用的通用协议。
- **Skill**：按需加载能力，减少上下文浪费，节省 token。
- **MCP Server**：把能力打包成可调用服务，供模型或 Agent 使用。
- **AI Agent**：把上面能力串起来，围绕目标自主规划和执行。

## 概念速览

| 名词       | 你可以把它理解成  | 主要作用                   |
| ---------- | ----------------- | -------------------------- |
| LLM        | 大脑              | 理解问题、生成回答         |
| RAG        | 外接记忆          | 让回答基于你的资料         |
| MCP        | 通用插座          | 统一工具调用方式           |
| Skill      | 能力说明书        | 按需激活能力，省 token     |
| MCP Server | 功能服务站        | 对外提供可调用工具         |
| Agent      | 项目经理 + 执行者 | 拆任务、调用工具、检查结果 |
